# WafR Management Console

A modern, secure management console for WafR customer support agents to manage users, monitor transactions, and generate reports.

## 🚀 Features

- **Secure Authentication**
  - Firebase-based authentication system
  - Protected routes and session management
  - Role-based access control

- **User Management**
  - Advanced user search by phone number
  - User profile viewing and management
  - Block/unblock user functionality
  - Bulk user actions
  - Export user data to CSV

- **Transaction Management**
  - View and monitor transaction history
  - Block/unblock transactions
  - Advanced filtering and sorting
  - Transaction analytics
  - Export transaction reports as PDF

- **Dashboard Analytics**
  - Real-time user statistics
  - Transaction metrics
  - Activity monitoring
  - Performance insights

## 🛠️ Tech Stack

- **Frontend**
  - React 18 with TypeScript
  - Vite for blazing fast development
  - TailwindCSS for styling
  - Lucide React for icons
  - React Router for navigation
  - React Hot Toast for notifications

- **Authentication**
  - Firebase Authentication
  - Protected routes
  - Session management

- **Data Management**
  - Context API for state management
  - Type-safe API integration
  - Real-time updates

- **PDF Generation**
  - jsPDF for report generation
  - Custom templating system

## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/wafr-management-console.git
   cd wafr-management-console
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## 📱 Usage

### User Search
1. Navigate to the Search page
2. Enter a phone number
3. View user details and transaction history
4. Perform actions like blocking/unblocking users

### Transaction Management
1. Go to Transactions page
2. View all transactions
3. Filter and sort transactions
4. Block/unblock transactions
5. Export transaction reports

### User Management
1. Access the Users page
2. View all user accounts
3. Filter and sort users
4. Perform bulk actions
5. Export user data
